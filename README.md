# 🐍 Snake Game — Python

A classic Snake Game built from scratch using **Python** and the **Turtle graphics library**. This project was developed as part of my journey through the **100 Days of Python** course, with a focus on Object-Oriented Programming (OOP).

The project recreates the classic Snake experience with keyboard controls, food collection, score tracking, and collision detection.

---

##  Features

*  Classic Snake gameplay
*  Arrow-key controls
*  Randomly positioned food
*  Real-time score tracking
*  Wall collision detection
*  Game Over functionality
*  Custom colors and game design
*  Object-Oriented Programming structure

---

##  Technologies Used

* **Python 3**
* **Turtle Graphics**

##  How to Play

1. Run `main.py`.
2. Use the **Arrow Keys** to control the snake.
3. Move the snake toward the food.
4. Each food item increases your score.
5. Avoid hitting the walls.
6. The game ends when the snake collides with a wall.

### Controls

| Key      | Action     |
| -------- | ---------- |
| ⬆️ Up    | Move Up    |
| ⬇️ Down  | Move Down  |
| ⬅️ Left  | Move Left  |
| ➡️ Right | Move Right |
